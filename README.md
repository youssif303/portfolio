# Personal Portfolio

A responsive, no-build static portfolio site for interview preparation.

## Preview

Open `index.html` in a browser. No install or build step is required.

## Personalize before sharing

Update these items in `index.html`:

- Update the name and `YM` initials if needed
- Location and availability text
- Email, LinkedIn, and GitHub links
- Project descriptions, evidence, and technology tags to match your actual contributions

The CARIAD case study uses a high-level generalized architecture and omits internal system names, hardware identifiers, screenshots, credentials, endpoint addresses, and operational settings. Confirm employer sharing rules before publishing.

## Files

- `index.html` — page content and project cards
- `styles.css` — responsive layout and visual styles
- `script.js` — current year in the footer
- `assets/ptz-mission-demo.mp4` and `assets/ptz-*.png` — thesis demo video and evaluation charts
- `assets/edgetrack-demo-1.mp4` and `assets/edgetrack-demo-2.mp4` — EdgeTrack dashboard and detection/tracking demos
- `assets/autobrain-*.png` — AutoBrain Lite manual-answer interface screenshots
